#+TITLE: tree-sitter-taggerscript

A tree-sitter grammar for MusicBrainz Picard's Tagger Script.

Picard file-naming and tagging scripts nest =$func(...)= calls and =%variables%=
deeply, and a script of any size is hard to read without highlighting. This
grammar parses Tagger Script into a syntax tree that editors use for
highlighting and structural editing; =queries/highlights.scm= provides the
highlight captures.

=$noop(...)= is treated as a comment: an external scanner (=src/scanner.c=)
consumes its body as one opaque token, balancing nested parentheses, so text
inside a comment is never parsed as functions or variables.

** Install

*** Emacs

Emacs 29 or later, built with tree-sitter support:

#+begin_src emacs-lisp
(add-to-list 'treesit-language-source-alist
             '(taggerscript "https://github.com/11xx/tree-sitter-taggerscript"))
(treesit-install-language-grammar 'taggerscript)
#+end_src

=picard-ts-mode=, part of [[https://github.com/11xx/picard-mode][picard-mode]], is a major mode built on this grammar.

*** From source

The repository commits the generated parser, so building needs only a C
compiler and =tree-sitter-cli=:

#+begin_src shell
tree-sitter test    # run the corpus in test/corpus
tree-sitter build   # write taggerscript.so in the current directory
#+end_src

With npm instead of a global =tree-sitter-cli=, =npm install= fetches the CLI
and =npm test= runs the corpus.
